# מפרט מערכת - אפליקציית ניהול משימות

## טכנולוגיות
- **Frontend:** React עם Tailwind CSS.
- **Backend:** Node.js עם Express.
- **Database:** MongoDB.

## החלטות עיצוב
החלטנו שהצבע העיקרי של המערכת יהיה **סגול כהה** (Deep Purple) כדי לשדר רצינות ורוגע.
הממשק תומך ב-RTL באופן מלא עבור משתמשים דוברי עברית.
