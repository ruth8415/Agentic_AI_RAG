# 📝 דוגמאות לשאילתות

## שאילתות סמנטיות (כל השלבים)

### שאלות כלליות
```
איך מתקינים את המערכת?
מה הארכיטקטורה של הפרויקט?
הסבר את תהליך ה-deployment
איך עובד ה-authentication?
```

### שאלות על עיצוב
```
מה הצבע העיקרי שנבחר לדיזיין?
איזה UI framework נבחר?
מה הגופן הראשי?
איך מטפלים ב-RTL?
```

### שאלות טכניות
```
איזה database נבחר ולמה?
מה מבנה ה-API?
איך מטפלים בשגיאות?
מה ה-caching strategy?
```

## שאילתות מובנות (שלב ג' בלבד)

### רשימות מלאות
```
תן לי רשימה של כל ההחלטות הטכניות
הצג את כל הכללים והנחיות
מה כל האזהרות במערכת?
רשום את כל התלויות
```

### מידע עדכני
```
מה ההנחיה העדכנית לגבי RTL?
מה ההחלטה האחרונה לגבי ה-DB?
איזה כלל עדכני יש לגבי authentication?
מה הגרסה הנוכחית של React?
```

### מבוסס זמן
```
אילו שינויים נעשו בשבוע האחרון?
מה ההחלטות שהתקבלו החודש?
אילו אזהרות נוספו לאחרונה?
תן לי עדכונים מ-3 הימים האחרונים
```

### סינון לפי תגיות
```
הצג החלטות הקשורות ל-backend
מה הכללים של ה-UI?
אזהרות ברמת חומרה גבוהה
תלויות של frontend
```

## שאילתות מורכבות

### שילוב סמנטי + מובנה
```
למה הוחלט על PostgreSQL ומתי?
איך משתמשים ב-Redis ומה ההנחיות?
מה השתנה ב-API בחודש האחרון ולמה?
```

### שאלות השוואתיות
```
מה ההבדל בין ההחלטה הישנה לחדשה?
איך השתנה הגישה ל-state management?
השווה בין הכללים של UI ל-backend
```
